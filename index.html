Logistics & Supply Chain Performance Analytics

A diagnostic analysis of delivery performance, operational risk and financial exposure across a global supply chain, using the public DataCo Supply Chain dataset.

180K+records (65,752 orders)
57.29%late-delivery rate
$20.13Msales tied to late orders

  • Python
  • Pandas
  • Power Query
  • DAX
  • Power BI
Finding
First Class shows a 95.32% late rate. Late orders carry 54.71% of total sales. Central Africa is at 57.96%, and Golf Bags & Carts at 68.85%. Several region and shipping-mode pairs concentrate the risk.
Advice
Investigate First Class operations, prioritize high-exposure regions, review carrier and routing for risky region and shipping-mode pairs, and monitor risky product categories.
Caveat
This is descriptive and diagnostic work. It shows patterns and exposure, not that delays cause profit changes.
How I built it
  1. Validated the data in Python and Pandas: missing values, duplicate rows, order IDs, delivery status and late-risk flags.
  2. Prepared it in Power Query and built the Power BI model.
  3. Wrote DAX measures for delivery, sales, profit and risk KPIs.
  4. Cross-checked Power BI results against Python calculations.
  5. Built four pages: overview, root cause, business impact and recommendations.

Method note: canceled shipments are excluded from delivery-rate denominators, and orders are counted with a distinct count because one order can have several items.

E-commerce Sales & Customer Analytics Dashboard

An end-to-end analysis from raw transaction data in PostgreSQL to a five-page Power BI report covering sales, customers, products, delivery performance and payments.

99Korders
95Kunique customers
3.05%repeat customer rate

  • PostgreSQL
  • SQL
  • Power Query
  • DAX
  • Power BI
Finding
Almost all customers buy once. About 3.05% come back, and 28.81% of orders are delayed. Average delivery takes about 12.43 days and the average review score is about 4.03 out of 5.
Advice
Run second-purchase and win-back campaigns, find consistently delayed regions, and review fulfillment bottlenecks.
How I built it

Eleven SQL scripts take the data from database setup through validation, cleaning, exploratory analysis, business analysis, RFM customer segmentation, views, indexes and the final analytics view.

In Power BI, DAX measures cover revenue, repeat customers, delivery rates and review rates. Text measures write an executive summary, risks and actions that update with the filters.
